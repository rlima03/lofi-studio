Política de privacidade

O Lofi Studio é uma ferramenta pessoal que roda apenas no computador do autor.

Dados do Google que o app usa

Com a autorização do dono da conta, o app usa a YouTube Data API apenas para enviar vídeos e miniaturas ao canal dele e ler o nome desse canal.

Armazenamento

O token de acesso fica guardado somente no computador onde o app roda, criptografado. Nenhum dado é enviado a servidores do app, porque eles não existem.

Compartilhamento

Nenhum dado é vendido, compartilhado ou usado para publicidade. O uso dos dados recebidos das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

Remoção

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions ou pelo botão Desconectar no app, que apaga o token.
